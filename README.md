# 😼 미트볼 라이트 (Meatball Lite) v0.26.0

## 본편 AI가 적는 사건 줄 (`<meatball>`)
`loc` `time` `date` `with` `ate` `slept` `washed` `rest` `worked` `buy` `earn` `got` `used` `wear` `act` `gift` `memory` `jealous` `pair` `promise` `weather` `status` `fate` `npc` `gone` `roll` `mind` `watch` `cell` `life` `meddle` `custom` — 숫자 줄(`허기: -10`, `cash: +5`, `aff: Leon +3`)도 받는다. 옛 미트볼의 다른 이름(가방 · 인물호감 · conditions …)도 읽고, 지운 칸 키(quest · news · sns · msg …)는 조용히 건너뛴다.

## dev에서 바뀐 점 · 더 세세해진 점
- **설정집**: 프로필 + 세계관 요약을 칸이 정해진 구조 하나로 합침. 본편에는 안 넣음. 인물마다 입력 칸, 토큰 수, 「다시 채우기」는 로어북이 바뀐 인물만.
- **사건 → 계산**: 증감은 설정집 규칙으로. 검증기가 돈 · 없는 물건을 막고, 이름 오타 · 존칭 · 영어 이름을 맞춤. 짐작한 값은 흐리게. 장면 자동 인식 · 어긋남 감지(+상태 고치기).
- **기록**: 메시지(extra)에서 매번 다시 만들어서 스와이프 · 삭제 · 브랜치가 저절로 맞음. 턴 요약 카드(줄마다 이유 · 되돌리기) · 타임라인 · 책갈피 · 그때 상태 · 그래프 점 → 그 메시지.
- **수치**: dev 게이지 · 능력치 + 욕구 카드(이유 · 다음 경계까지 시간 · 회복 방법). 위험 → 기간 딱지 저절로.
- **관계**: dev 카드 + 다음 단계 해금 · 최근 변화 · 속셈 · 기억 · 취향 도감 · 특성 궁합(반대가 끌림) · 숫자 숨기기.
- **지도**: dev 노선도 + 길 안내 · 지금 가면 만날 사람 · 장소별 물가 · 쉬기 효과 · 건물 안은 엘리베이터식 + 사진.
- **달력**: dev 월 화면 + 「다음 날 아침」(밤잠 포함) · 이 날로 이동 · 하루 전 알림.
- **주사위**: d20 · 확률 고리 · 보정 내역 · 대성공/대실패 연출 · 오늘 운세 주사위.
- **새 기능**: 🧬 특성 30개(심즈 3 · 4 개념 · 3개 고름 · 나만의 특성) · 지금 원하는 것 3개 · 🍀 운세 쪽지 · 홈 위젯(지금 할 수 있는 일 · 곧 일어날 일 · 앱 배지) · 마켓 · 🌐 영어 저장 번역 · 꾸미기(갈무리 도트 글꼴) · 😼 dev 마스코트 + 콘팩 60개.

## 미트볼 선택지와의 통로 (`globalThis.MeatballLite`)
`version` · `ready()` · `state()`(시각 · 날짜 글 · 장소 · 같이 있는 사람 · 돈 · 욕구 · 게이지 · 능력치 · 상태 · 위험) · `scene()`(지금 장소에서 살 수 있는 것 `{ name, price }` · 장면 속 인물 `{ name, want }`) · `diceParts(attr)` · `preview(label)`(배지 글만: 「−3골드 · 허기 +20」 · 🎁 · 만날 사람 · 돈 부족 — 이 가게 물건 → 소지품 → 인물 → 장소 이름으로 먼저 맞추고, 안 맞을 때만 「잠 · 먹 · 씻」 낱말) · `luck(label)` · `paused()` · 신호 `meatlite:update`. 테마는 CSS 변수 `--ml-accent` `--ml-font` `--ml-size` `--ml-radius` `--ml-border` `--ml-shadow`로 문서 전체에 늘 열어 둔다.
