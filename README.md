# 😼 미트볼 라이트 v0.3.0

dev 미트볼 2.10.1에서 고른 기능만 새 구조로 다시 짠 판. **계산은 코드가, AI는 사건만** 적는다.
함께 쓰는 확장: [미트볼 선택지](https://github.com/dfzfs/meatball-lite-choices) — 선택지 버튼에 대가 미리 보기(「−3골드 · 허기 +20」).

## 들어 있는 것
- 📘 상태창 설정집 (세계 · 나 · 인물별 칸 구조 · 본편엔 안 넣음 · 토큰 수 · 로어북에서 다시 채우기)
- 사건 태그 엔진 (`ate: 빵` · `buy: 빵 | 3` · `act: Leon | 칭찬` · `gift: Leon | 꽃` · `slept: 6h` …) + 숫자 줄도 받음
- 검증기: 돈 · 없는 물건 막고 「확인 필요」 · 이름 오타 · 존칭 맞추기 · 범위 자르기
- 욕구는 달력 시간으로 줄어듦 · 정상/주의/위험 · 위험이면 주사위 보정 · 날씨 영향
- 관계: 단계 · 다음까지 남은 거리 · 로맨스 보정 · 단계 건너뛰기 막기 · 애정 꺼 두기 · 질투 · 감정 기억 · 취향 도감 · 선물 보너스 · 빠진 사람 · 합치기 · 얼굴 · 숫자 숨기기
- 상태 딱지(운명 저주 · 축복 포함 · 기간 끝나면 풀림) · 약속 장부
- 이야기 영향력 게이지 0~4 (전체 + 기능별 · 프리셋 · 이 채팅만/전체)
- 턴 요약 카드 (줄마다 이유 · 되돌리기 · 짐작은 흐리게 · ✋직접 · ✍손댐)
- 기록 · 되돌아보기 (메시지에서 매번 만듦 · 거르기 · 이동 · 책갈피 · 그때 상태 · 하이라이트 · 그래프)
- 지도 · 달력 · 세계 소식(AI 0회) · 추천 음악 · 이 장면의 한 구절 · 속마음(인물 · 관전자 · 세포) · 내 탭(+최면 어플 템플릿)
- 미니 선택지: 버튼은 이야기 문장을 입력창에 넣기만
- 화면: HUD · 미니바 · 전체화면 · 직접 고르기 꾸미기
- 일시정지 · 다음 1번 건너뛰기 · OOC · 조용한 생성 제외 · 🏎 부하 재기 · 🔍 검색 · 백업 · 카드에 붙이기 · 옛 미트볼 옮겨 오기
- 🔌 `globalThis.MeatballLite` 읽기 통로 + `meatlite:update` 이벤트
