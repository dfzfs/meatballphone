# 😼 미트볼 라이트 (Meatball Lite) v0.25.0

dev 미트볼 2.10.1에서 고른 기능만 새 구조로 다시 짠 상태창 확장. **계산은 코드가, AI는 사건만** 적고, **본편에는 결과값만** 간다.
함께 쓰는 확장: [미트볼 선택지](https://github.com/dfzfs/meatball-lite-choices) — 선택지 버튼에 대가 미리 보기 · 🍀 운세 · 주사위 보정.

- 설치: 실리태번 › 확장 › 확장 설치 → `https://github.com/dfzfs/meatball-lite`
- 시작: 확장 설정 › 「📘 상태창 만들기 (AI 1회)」 또는 「⚡ 바로 시작 (AI 0회)」
- 옛 미트볼과 같이 켜져 있으면 라이트는 쉰다. 옛 채팅은 「🍖 옛 미트볼 옮겨 오기」.

## 본편 AI가 적는 사건 줄 (`<meatball>`)
`loc` `time` `date` `with` `ate` `slept` `washed` `rest` `worked` `buy` `earn` `got` `used` `wear` `act` `gift` `memory` `jealous` `pair` `promise` `weather` `status` `fate` `npc` `gone` `roll` `mind` `watch` `cell` `life` `meddle` `custom` `exchange` `haggle` — 숫자 줄(`허기: -10`, `cash: +5`, `cash: +3 은화`, `aff: Leon +3`)도 받는다. 옛 미트볼의 다른 이름(가방 · 인물호감 · conditions …)도 읽고, 지운 칸 키(quest · news · sns · msg …)는 조용히 건너뛴다.

## 이야기 영향력 게이지 (0~4)
0 기록만 · 1 은근히(경계를 넘을 때만) · 2 보통(지금 사실 + 연출 힌트) · 3 강하게(결과를 지키게) · 4 주도(설렘 · 화면 밖 사건 · 손댄다). 전체 + 기능별 · 프리셋(조용히 · 균형 · 게임처럼 · 연애 위주) · 이 채팅만/전체. 🎚️ 영향력 앱에서 **지금 본편에 가는 글**과 기능별 단계 동작 표를 볼 수 있다.

## dev에서 바뀐 점 · 더 세세해진 점
- **설정집**: 프로필 + 세계관 요약을 칸이 정해진 구조 하나로 합침. 본편에는 안 넣음. 인물마다 입력 칸, 토큰 수, 「다시 채우기」는 로어북이 바뀐 인물만.
- **사건 → 계산**: 증감은 설정집 규칙으로. 검증기가 돈 · 없는 물건을 막고, 이름 오타 · 존칭 · 영어 이름을 맞춤. 짐작한 값은 흐리게. 장면 자동 인식 · 어긋남 감지(+상태 고치기).
- **기록**: 메시지(extra)에서 매번 다시 만들어서 스와이프 · 삭제 · 브랜치가 저절로 맞음. 턴 요약 카드(줄마다 이유 · 되돌리기) · 타임라인 · 책갈피 · 그때 상태 · 그래프 점 → 그 메시지.
- **수치**: dev 게이지 · 능력치 + 욕구 카드(이유 · 다음 경계까지 시간 · 회복 방법). 위험 → 기간 딱지 저절로.
- **관계**: dev 카드 + 다음 단계 해금 · 최근 변화 · 속셈 · 기억 · 취향 도감 · 별자리 · 궁합 · 숫자 숨기기.
- **지도**: dev 노선도 + 길 안내 · 지금 가면 만날 사람 · 장소별 물가 · 쉬기 효과 · 건물 안은 엘리베이터식 + 사진.
- **달력**: dev 월 화면 + 「다음 날 아침」(밤잠 포함) · 이 날로 이동 · 하루 전 알림.
- **주사위**: d20 · 확률 고리 · 보정 내역 · 대성공/대실패 연출 · 오늘 운세 주사위.
- **새 기능**: 🧬 특성(심즈 3 · 4 개념 · 3개 고름) · 별자리 · 야망(심즈 3 평생 소원) · 지금 원하는 것 · 🍀 운세 쪽지 · 홈 위젯(지금 할 수 있는 일 · 곧 일어날 일 · 앱 배지) · 마켓 · 🌐 영어 저장 번역 · 꾸미기(갈무리 도트 글꼴) · 😼 dev 마스코트 + 콘팩 60개.

4. 스와이프 · 삭제 · 이어쓰기 · 브랜치 뒤 숫자 · 기록
5. 퀵리플라이 · `/gen` · 일시정지 · 다음 1번 건너뛰기 · OOC

8. 미트볼 선택지와 같이: 대가 미리 보기 · 🍀 · 칩 위에 붙기
9. 옛 미트볼 채팅 옮겨 오기 · 옛 미트볼과 같이 켰을 때 쉬는지
